# Privacy

Rust Code Studio is an open-source collection of local agent instructions and scripts. It does
not operate a hosted service, include telemetry, or send repository contents to the maintainer.

Your agent host and any tools you choose to invoke may process repository files, command output,
conversation context, or configured memory data under their own privacy terms. Review and trust
plugin hooks before enabling them, and do not configure third-party tools with data they should
not receive.

Questions can be filed in the issue tracker of the repository from which you installed the plugin.
