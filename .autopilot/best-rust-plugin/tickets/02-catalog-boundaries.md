# T02 — Каталог перестаёт путать соседние скиллы

**Требования:** R01.2, R01, R06i · **Зона:** `plugins/rust-studio/skills/*/SKILL.md` (8 файлов),
`plugins/rust-studio/scripts/validate-distribution.sh` · **Блокеры:** T01 · **Волна:** 2

## Что не так
Измерено: границу «## When NOT this skill» имеют **6 из 62** скиллов. Четыре пары описаний
пересекаются настолько, что агент выбирает между ними наугад (Jaccard ≥ 0.20 по содержательным
словам): `/design-api`~`/team-api`, `/publish`~`/team-release`, `/help`~`/start`,
`/brainstorm`~`/spec`. Источник — SkillResolve-Bench (arXiv 2606.10388): извлечение деградирует
с ростом каталога, причина — пересекающиеся описания и отсутствие явных границ.

## Приёмка
1. Каждый из **восьми** скиллов получает раздел «## When NOT this skill», который называет
   соседа **поимённо** и говорит, чем тот отличается. Не общими словами: «нужен готовый API с
   тестами и ревью → `/team-api`».
2. Гейт в `validate-distribution.sh`: считает пересечение содержательных слов описаний по всем
   парам; падает, если пара ≥ 0.20 и **хотя бы у одного** из двух нет раздела «When NOT this
   skill», называющего второго. Реализация — python3-heredoc, как уже сделанный anchor-гейт.
3. Гейт доказан **намеренной регрессией**: подсадить нарушение, показать падение, откатить.
4. После правок: `./scripts/sync-references.sh`, `node scripts/generate-openai-metadata.mjs`,
   `./scripts/validate-distribution.sh`, `bun test` — всё зелёное.
5. Число границ пересчитано и названо в отчёте (ожидается 14/62).

## Не делать
Не переписывать описания ради снижения метрики — описания несут триггеры извлечения.
Разводить надо границей, а не обеднением описания.
