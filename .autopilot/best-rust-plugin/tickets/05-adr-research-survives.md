# T05 — Исследование переживает прогон

**Требования:** R01.5, R02, R03, R04, R06i · **Зона:** `plugins/rust-studio/docs/adr/`,
`/mnt/data/dev/rust-studio/CLAUDE.md` · **Блокеры:** нет · **Волна:** 1

## Почему
`.autopilot/` умирает вместе с прогоном. Бриф прямо просил «изучи» — если результат не выходит
за пределы прогона, требование не выполнено, а следующая сессия перечитает то же самое.
`docs/adr/` в репозитории нет — создать.

## Приёмка
ADR (`docs/adr/0001-agent-skills-research-2026-09.md`) содержит:
1. **F1–F7** с датами и проверяемыми ссылками: SkillResolve-Bench (arXiv 2606.10388),
   SkillsBench (arXiv 2602.12670), «Agent Skills: Portable, Popular, Unmeasured», DeepSeek
   Harness (InfoQ / Developers Digest / VentureBeat / The Register, авг. 2026), экосистема
   Agent Skills, состояние тулчейна (rustc 1.98.0, 2026-08-18).
2. **Решение по DeepSeek Harness и его обоснование:** третьим хостом не делается — `@deepseek/harness`
   в npm 404, `deepseek-ai/harness` на GitHub 404, а `dsh@1.0.1` / `deepseek-harness@0.0.1` —
   имена из блог-постов. Ставить их запрещает `docs/untrusted-context.md`; шипнуть манифест
   хоста, ни разу его не запустив, — непроверенное утверждение о совместимости. Условие
   пересмотра названо: появление запускаемого первоисточника.
3. **Как ограничен «и тд»:** читалось то, что меняет строку в этом плагине; не читалось —
   общий AI-ньюс, релизы моделей, продуктовые анонсы.
4. **Метод замера актуальности доктрины и его ошибка:** грепать надо обе записи
   (`let-chains` и `let_chains`) — первый замер дал ложный разрыв из-за дефиса; команда для
   перезамера записана. Там же — что покрытие ground truth составляет 6/33 агентов и 7/20
   доменов правил.
5. Ссылка на ADR из корневого `CLAUDE.md` (внутри маркеров `autopilot`).
6. `./scripts/validate-distribution.sh` — зелёный (ADR не должен ломать sync-references).
